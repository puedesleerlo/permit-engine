Failure modes

What can go wrong, how it is caught, and what happens then. Each row is marked by whether a test really covers it. A row with no test is not hidden.

How to read the marks

33 rows in all. The build stops if a test named here no longer exists. All the named tests passed when these marks were checked on 2026-11-03, using recorded fixtures with no model calls. The code is private for now, so a reader cannot run them from this site.

17

Tested

A named test checks this row.

9

Partly tested

A named test checks part of it. The row says which part is not.

6

No test

No named test covers it: an operating step, an accepted risk, or a report. The row says which.

1

Not built

The design describes it, and the code does not exist yet.
