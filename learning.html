This run starts from the untrained first guess. The officer’s rubric and the labels come from the same answer key, so these numbers show how the learning works, not how real events turn out.

Why every review teaches

Teaching only from disagreements made the first guess worse, because it saw only the cases that guess got wrong.

Mixed outcomes flagged a missing question

To see whether the system can notice a question its tree lacks, a question about major crossings was left out on purpose. Cases reaching one branch then had mixed outcomes, which raised a flag, and a person added the question and released it.

People keep the last word

  • Simulated officer: an LLM following the expert rubric

    A real deployment would use a person. The stand-in matched the answer key on 95.7% of outcomes, which is expected because its rubric was written from that key.

  • Rules never change themselves

    Reviews move weights. Written rules change only when a person edits them.

  • A person releases every rule change

    Reviews update the weights inside a run, and each decision records the version it used. Rule and question changes need a person.
