What this test cannot show

About 3 risky approvals in 52 gives a Wilson interval of roughly 2% to 16%, so this test cannot confirm a 5% target. It can only show when risky approvals are clearly above it.

What counts as passing

All three must hold on the sealed test, or the experiment is published as a fail.

  • Lower loss

    Trained trees have lower loss than the first guess and than the shuffled-label control, with each 95% interval on the difference excluding zero.

  • More approvals

    Trained trees approve a larger share of cases automatically than the first guess, with a 95% interval on the difference excluding zero.

  • No clear safety failure

    It fails on safety only if the test clearly shows risky approvals above 5%: the lower end of the 95% Wilson interval on the share labelled risky among approvals is above 5%.

What this rule accepts

In simulation, on the same sizes, this rule passes a working system about five times in six, so a system that works can still fail. It also lets some thresholds that are too loose through. It catches only a clear safety failure, because the test is too small to confirm a 5% target. Those figures are from a simulation with a planted truth, not from this test.

The cases

One event type, a street race. All synthetic, from one seed. Splits are made by request, so the tones of one request never cross a split.

180 training requests
Fit the leaf weights.
120 validation requests
Choose released thresholds, test the crossings question, and supply the replay’s cases.
100 test requests, sealed
Used once, by a ledger that is written before their labels are opened and refuses a second run. Never shown in the replay or corrected.
60 tone cases
20 of the test requests, rewritten in 3 more tones. With the 100, that makes 160 test cases.

Each case keeps its parts in separate files: the hidden facts, the application, and the labels. Reality and evidence vary separately, so a race can have an escort arranged and no letter on file, or a letter that names another date. Some written variants appear only in the test split, so repeated templates flatter the results less.

What these sizes cannot show

The report states these limits, and so does this page.

  • About 3 risky approvals in 52 gives a Wilson interval of roughly 2% to 16%, so the test cannot confirm a 5% target. It can show only when risky approvals are clearly above it.
  • The labels are the author’s. The trees ask about the same factors as the truth table, so training is close to guaranteed to learn it. Beating the control shows the labels matter. It says nothing about real events.
  • One run is one run. The replay’s curve is read on far fewer cases than the simulations behind this design, so it need not rise at every step.
  • Only labels the author did not write, from real outcomes or an independent expert, could show whether the trees or Jev’s own judgement is closer to real risk. None exist here.
