Testing and impact

Permit Engine will be compared with a simpler design: one AI model that reads the request and says yes or no. The same request should get the same decision, however it is written.

What I built (individual project): a generator for 240 test requests with known answers, the staged decision system, a learner that tunes how cautious it is, and a test harness that compares it with one AI model.Results pending

The simpler design: one AI model

One AI model reads the whole request and is asked one question: approve or deny? This is the baseline Permit Engine is compared with.

Permit Engine

Runs every check on every case: the fact check, the risk tree and the written rules. Unsure cases go to an officer.

It also scores how pushy each letter is, but that score is never used to decide. It is there to prove tone has no effect.

In technical terms

Each request has a correct decision worked out from the ordinance, and the cases are split into training and test sets. The harness also tracks wrong denials, decisions officers overturn, officer minutes per case, whether a case gets the same answer when run twice, and days to fix a mistake.

Stack: Python. An agentic LLM reads applications and checks facts. TypeSafe Jev scores likelihood and impact. Open Policy Agent (Rego) holds the permit rules. Calibration (isotonic regression or Platt scaling) on officers’ rulings sets how cautious the system is.

Before the system gets more say

Passing the test is not enough. At launch, an officer checks every decision. A type of decision becomes automatic only when all four of these hold. Then officers decide uncertain cases, sign every denial and check 1 in 10 automatic approvals.

  • It is accurate on the test cases

    Its decisions match the right answers, worked out from the ordinance, on cases it never trained on.

  • Officers catch its mistakes

    On spot checks, an officer decides first, without seeing the system’s answer, then compares. Blind spot checks must be in place and catching its mistakes.

  • The stop switch works in a drill

    One switch sends every open case to an officer. Nothing is issued automatically until it is lifted.

  • A wrong permit can be revoked

    If a mistake is found after a permit is issued, an officer can take it back, and the log shows why.

Until then, officers check its work, and their rulings tune how cautious it is. Read how the system learns from officers.

Where else it works

The permit office is only the demo. The same engine fits any decision where AI checks evidence against written rules and a person reviews the hard cases.
